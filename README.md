### Olá, eu sou o Yohan Ryuking 👋

**Full Stack Developer | CTO @ TenloListo**

Construo produtos **SaaS** do zero até produção: arquitetura, backend, frontend e liderança técnica. Meu foco é **TypeScript** (React, Next.js, Angular, NestJS), **Python** (FastAPI, ETL) e **PostgreSQL**, e também desenvolvo aplicações com **IA** (agentes com tool calling, RAG e visão computacional).

- 🚀 CTO do [TenloListo](https://beta.tenlolisto.com), um ecossistema SaaS para o comércio local.
- 🧠 Gosto de projetos com decisões técnicas bem documentadas (ADRs), testes e segurança pensada desde o início.
- 🌎 Aberto a vagas **remotas**, com foco no mercado brasileiro.
